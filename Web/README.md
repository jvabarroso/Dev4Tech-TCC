# Landing Page Workflow

Uma landing page moderna e responsiva para o sistema de gestão Workflow, desenvolvida com HTML, CSS e JavaScript.

## 🚀 Características

- **Design Moderno**: Interface limpa e profissional
- **Totalmente Responsiva**: Funciona perfeitamente em desktop, tablet e mobile
- **Animações Suaves**: Efeitos de entrada e transições elegantes
- **Performance Otimizada**: Carregamento rápido e eficiente
- **Acessibilidade**: Código semântico e bem estruturado

## 📁 Estrutura do Projeto

```
web/
├── index.html          # Página principal
├── styles.css          # Estilos CSS
├── script.js           # Funcionalidades JavaScript
└── README.md           # Documentação
```

## 🎨 Design

A landing page inclui:

- **Header Fixo**: Navegação com logo e menu
- **Seção Hero**: Título principal, descrição e call-to-action
- **Botões Interativos**: Download e demonstração
- **Imagem de Destaque**: Foto de equipe trabalhando
- **Informações Adicionais**: Versão desktop e preços
- **Seção Sobre o Projeto**: Apresentação das funcionalidades do sistema
- **Grid de Funcionalidades**: 6 cards destacando os recursos principais
- **Seção Benefícios**: Por que usar o WORKFLOW com 4 cards de benefícios
- **Ilustração Interativa**: Gráfico de tablet com stylus
- **Seção Nossa Equipe**: Apresentação da equipe e valores do projeto
- **Cards de Valores**: Educação, inclusão digital e inovação sustentável
- **Seção CTA**: Call to Action final com botões de download
- **Footer**: Informações de contato e benefícios do produto

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilos modernos com Grid e Flexbox
- **JavaScript**: Interatividade e animações
- **Font Awesome**: Ícones
- **Google Fonts**: Tipografia Inter

## 📱 Responsividade

A página é totalmente responsiva com breakpoints para:
- **Desktop**: 1200px+
- **Tablet**: 768px - 1199px
- **Mobile**: 320px - 767px

## 🚀 Como Usar

1. Clone ou baixe os arquivos
2. Abra o `index.html` em um navegador
3. A página carregará automaticamente com todas as funcionalidades

## 🎯 Funcionalidades

- **Navegação Suave**: Scroll suave entre seções
- **Header Dinâmico**: Transparência ao rolar
- **Botões Interativos**: Efeitos hover e click
- **Animações de Entrada**: Elementos aparecem com fade-in
- **Links Funcionais**: Preparado para integração com backend

## 🔧 Personalização

Para personalizar a landing page:

1. **Cores**: Edite as variáveis CSS no arquivo `styles.css`
2. **Conteúdo**: Modifique o texto no `index.html`
3. **Imagens**: Substitua a URL da imagem na seção hero
4. **Links**: Atualize os hrefs nos botões e navegação
